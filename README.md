# CodeOrbit-Basic-Calculator
This project is a command-line Python calculator for basic arithmetic (addition, subtraction, multiplication, division). It features an interactive loop for continuous calculations until the user exits. It includes robust error handling to safely manage invalid inputs and division by zero, making it an ideal beginner-friendly coding project.

## Features
- Addition
- Subtraction
- Multiplication
- Division (with zero-division protection)
- Input validation

## How to Run
1. Ensure you have Python installed on your system.
2. Run the script from the terminal:
   ```bash
   python calculator.py
   ```
3. Follow the on-screen prompts to perform calculations.

## Objective
This is only a beginner-friendly project for understanding basic concepts of Core Python Programming.
